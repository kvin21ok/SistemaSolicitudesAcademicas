# Sistema de Gestión de Solicitudes Académicas

Sistema de consola desarrollado en Python para gestionar
solicitudes realizadas por estudiantes de una institución educativa.

## Funcionalidades

- Registrar solicitudes.
- Cambiar el estado de las solicitudes.
- Asignar responsables.
- Buscar y filtrar solicitudes.
- Generar reportes básicos.

## Tecnologías

- Python
- Programación Orientada a Objetos
- Persistencia mediante archivos JSON
- unittest para pruebas

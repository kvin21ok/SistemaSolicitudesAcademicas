# Documentación del proyecto

Esta carpeta reúne la documentación técnica complementaria del Sistema de Gestión de Solicitudes Académicas.

## Contenido

- `REVISION_TECNICA.md`: checklist de Code Review, observaciones, feedback y criterios de aceptación.
- `DECISIONES_TECNICAS.md`: tecnologías utilizadas, decisiones de diseño, persistencia, validaciones y pruebas.

## Evidencias

Las capturas del desarrollo y de las pruebas se encuentran en la carpeta `evidencias`, ubicada en la raíz del repositorio.

## Control de versiones

El historial de commits y los tags de Git permiten identificar la versión inicial, el diagnóstico, la refactorización, las pruebas y la documentación del proyecto.
